# 柔和专业医疗风格 — 前端设计规范

> **适用项目**：Surgery RAG Agent（PC 端）
> **服务对象**：外科医生（查询手术步骤、医学知识） + 患者（问诊、健康咨询）
> **核心原则**：在专业可信与温暖安抚之间取得平衡。大屏布局让医生高效获取信息，柔和视觉语言减轻患者焦虑。洁净、专注、透气。

---

## 1. 设计理念

本产品同时面对两类差异极大的用户：需要快速查阅手术方案的外科医生，以及对医学知识一知半解、可能焦虑的患者。设计必须在两者之间架桥：

- **对医生**：信息密度合理、操作路径短、视觉噪音低，支持沉浸式长时间使用。
- **对患者**：色彩温暖不冰冷、交互反馈及时、关键安全提示醒目不惊吓。
- **全局基调**：现代极简框架 + 医疗严谨感 + 人文关怀细节。干净得如同消过毒的手术台，但不冰冷。

## 2. 色彩体系（方案 B：暖杏蓝）

### 2.1 核心色板

| 色值名称 | 色值 | 用途 |
|----------|------|------|
| `--color-primary` | `hsl(200, 65%, 40%)` | 主按钮、链接、焦点环、选中态 |
| `--color-primary-light` | `hsl(200, 65%, 92%)` | AI 气泡底色、主色浅底标签 |
| `--color-primary-hover` | `hsl(200, 65%, 35%)` | 主按钮 hover |
| `--color-primary-active` | `hsl(200, 65%, 30%)` | 主按钮 active/按下 |
| `--color-accent` | `hsl(25, 55%, 52%)` | 辅助强调色：图标装饰、徽章、步骤高亮、暖色提示 |
| `--color-accent-light` | `hsl(25, 55%, 93%)` | 辅助色浅底（如免责提示背景） |

### 2.2 背景层次

| 色值名称 | 色值 | 用途 |

| `--bg-surface` | `#ffffff` | 卡片、对话框、面板 |
| `--bg-sidebar` | `hsl(200, 10%, 95%)` | 侧边栏底色（微暖灰蓝） |
| `--bg-input` | `hsl(200, 10%, 97%)` | 输入框默认背景 |
| `--bg-hover` | `hsl(200, 15%, 93%)` | 列表项/行 hover |

### 2.3 文字色

| 色值名称 | 色值 | 用途 |

| `--text-link` | `hsl(200, 65%, 40%)` | 链接（同主色） |

### 2.4 语义色

| 色值名称 | 色值 | 用途 |
|----------|------|------|
| `--color-success` | `hsl(155, 50%, 40%)` | 完成状态、对勾图标 |
| `--color-warning` | `hsl(38, 70%, 48%)` | 免责提醒、温和告警（底线暖黄） |
| `--color-danger` | `hsl(0, 60%, 48%)` | 紧急入口 120、删除按钮、错误 |
| `--color-danger-soft` | `hsl(0, 55%, 55%)` | 低危操作（次要危险按钮） |

### 2.5 分割线与边框

| 色值名称 | 色值 | 用途 |
|----------|------|------|
| `--border-default` | `hsl(210, 8%, 88%)` | 默认分割线、卡片边框 |

| `--border-focus` | `hsl(200, 65%, 40%)` | 输入框聚焦光环（box-shadow 渲染） |

### 2.6 暗色主题（医生模式可选）

| 色值名称 | 色值 | 用途 |
|----------|------|------|
| `--dark-bg-canvas` | `hsl(215, 25%, 10%)` | 暗色画布 |
| `--dark-bg-surface` | `hsl(215, 18%, 15%)` | 暗色卡片/面板 |
| `--dark-bg-sidebar` | `hsl(215, 20%, 12%)` | 暗色侧边栏 |
| `--dark-text-primary` | `hsl(210, 10%, 90%)` | 暗色正文 |
| `--dark-text-secondary` | `hsl(210, 8%, 65%)` | 暗色次要文本 |

### 2.7 色彩使用规则

- 主色 `--color-primary` 仅用于可交互元素（按钮、链接、焦点环）和少量装饰。**禁止**用作大面积背景。
- 辅助色 `--color-accent` 占整体色彩面积的 3-5%，起到"暖意点缀"作用。
- 所有文字与所在背景的对比度 ≥ 4.5:1（正文必须 ≥ 7:1）。
- 不依赖颜色作为唯一信息传达手段（如错误状态必须配图标）。

## 3. 排版体系

### 3.1 字体栈

```css
font-family: "Inter", "PingFang SC", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
```

- Inter：英文/数字首选，字重齐全，屏幕可读性优异。
- PingFang SC：中文首选，macOS/iOS 原生渲染最优。
- 回退：系统默认无衬线。

### 3.2 字号阶梯（基于 4px）

| 标签 | 字号 | 行高 | 用途 |
|------|------|------|------|
| `xs` | `13px` | 1.5 | 辅助标注、时间戳、引用卡片内文本 |
| `sm` | `14px` | 1.5 | 侧边栏项、标签、按钮文字 |
| `base` | `16px` | 1.6 | 全局正文、对话气泡内容 |
| `md` | `18px` | 1.5 | 会话标题、卡片标题 |
| `lg` | `22px` | 1.4 | 区块标题、面板标题 |
| `xl` | `28px` | 1.3 | 页面标题、欢迎页问候语 |
| `2xl` | `36px` | 1.2 | 品牌标志文字（顶部栏） |

### 3.3 行宽控制

- 正文段落最大宽度 `72ch`。
- 信息密集型文本（手术步骤、指南摘要）可放宽至 `80ch`。
- 对话气泡最大宽度 `70%`（相对消息容器），单行长文本自动断行。

### 3.4 字重

- 正文：400（regular）。
- 标题：600（semibold）。
- 强调/加粗：600。
- 代码块内医学数据：500（medium），等宽字体 `"JetBrains Mono", "SF Mono", monospace`。

### 4.2 尺寸规范

| 区域 | 宽度 | 备注 |
|------|------|------|
| 顶部导航栏 | 全宽，高度 `56px` | 固定定位 |
| 侧边栏 | `260px`（展开）/ `64px`（折叠） | 折叠态仅显示图标列 |
| 主对话区 | `flex: 1`，`max-width: 880px` | 居中，左右自动边距 |
| 信息面板 | `340px` | 可选，默认隐藏，RAG 检索后自动展开 |
| 主对话区内容 | `padding: 0 24px` | 保证文字不贴边 |

### 4.3 侧边栏

- 展开宽度 `260px`，折叠宽度 `64px`。
- 折叠态：仅显示图标（新建会话、历史列表 icon、用户头像），hover 时 tooltip 显示文字。
- 折叠/展开切换按钮置于侧边栏顶部，图标为 `←` / `→`。
- 折叠过渡动画 `width 250ms cubic-bezier(0.2, 0, 0.8, 1)`。
- 会话列表项：padding `10px 12px`，间距 `4px`，圆角 `8px`，单行省略。

### 4.4 信息面板（右侧）

- 宽度 `340px`，从右侧滑入，`transform: translateX()` 过渡 `280ms`。
- 内含：RAG 检索来源列表、引用摘要卡片、手术步骤时间轴。
- 可通过键盘快捷键 `Ctrl+B` 切换显示。

### 4.5 间距量表（4px 基数）

```

```

| 场景 | 间距 |
|------|------|
| 组件内部 padding | `12px` 或 `16px` |
| 对话气泡间距 | `16px` |

## 6. 动效规范

### 6.1 统一缓动

```css
--ease-standard: cubic-bezier(0.2, 0, 0.8, 1);
```

### 6.2 时长

| 类型 | 时长 | 缓动 |
|------|------|------|
| 微交互（hover/active） | `150ms` | `ease-out` |
| 组件过渡（折叠/展开/滑入） | `250ms` | `var(--ease-standard)` |
| 页面转场 | `300ms` | `var(--ease-standard)` |
| 浮现/淡入（消息、卡片） | `200ms` + `fade-in` + `translateY(4px)` | `ease-out` |

### 6.3 微交互细节

- **按钮 hover**：背景亮度 +5%，`transition: background-color 150ms ease-out`。
- **按钮 active**：亮度 -5%，`scale(0.98)`。
- **卡片 hover**：`translateY(-2px)` + 阴影从 `--shadow-sm` 过渡到 `--shadow-lg`，`200ms`。
- **侧边栏折叠**：`width` + `opacity` 过渡 `250ms var(--ease-standard)`。
- **流式输出（AI 回复）**：光标闪烁指示器（`|` 字符 pulse 动画，周期 `800ms`），新 token 字符无动画直接追加，整条消息完成后淡入来源卡片。
- **引用来源**：点击引用标记 `[1]` 后，右侧面板平滑滚动到对应来源项，黄色高亮背景闪烁 `1.5s` 后消退。
- **加载状态**：心跳波纹动画（`scale` 脉冲 `1 → 1.03 → 1`，`1.2s` 循环），使用辅助暖杏色。

## 7. 组件特定变体

### 7.1 对话气泡

| 属性 | 用户气泡 | AI 气泡 |
|------|----------|---------|
| 对齐 | 右对齐 | 左对齐 |
| 底色 | `hsl(200, 10%, 94%)`（浅暖灰） | `hsl(200, 65%, 94%)`（浅暖蓝） |
| 最大宽度 | `70%` | `70%` |
| 圆角 | `16px 16px 4px 16px` | `16px 16px 16px 4px` |
| 文字色 | `--text-primary` | `--text-primary` |
| 字号 | `15px` | `15px` |
| 行高 | `1.6` | `1.6` |

- 气泡下方面向来源卡片，间距 `8px`。
- 用户气泡不显示头像，AI 气泡左侧显示小型圆形头像（24px，主色底 + 白色十字图标）。

### 7.2 RAG 引用卡片

- 出现在 AI 消息气泡下方最多 5 条来源。
- 结构：`[编号] 文档标题 — 第 X 页`。
- 可点击展开查看简短文本摘要（200px 高度限制，超出省略）。
- 卡片底色 `--bg-canvas`，圆角 `8px`，border `1px solid var(--border-light)`，padding `10px 12px`。
- 字号 `13px`，行高 `1.5`，文字色 `--text-secondary`。
- 悬停变蓝：左边框变为 `3px solid var(--color-primary)`。

### 7.3 手术步骤展示

- 使用垂直时间轴样式（左侧竖线 + 圆形节点）。
- 已完成步骤：绿色节点 + `--color-success` 对勾图标。
- 当前步骤：主色填充节点 + 加粗标题 + 主色浅底卡片。
- 未完成步骤：灰色空心节点 + `--text-disabled` 文字。
- 节点直径 `12px`，竖线 `2px solid var(--border-default)`。
- 步骤卡片 padding `12px 16px`，圆角 `8px`。

### 7.4 搜索/提问栏（输入区域）

- **定位**：固定于主对话区底部，`position: sticky; bottom: 0`。
- **背景渐变**：输入区上方 `40px` 渐变透明遮罩（`linear-gradient(transparent, var(--bg-canvas))`），视觉上让消息"沉入"输入框后方。
- **输入框**：
  - 宽度 `100%`，最大 `760px`，水平居中。
  - 最小高度 `56px`，最大 `200px`（自动扩展）。
  - 圆角 `12px`，边框 `1px solid var(--border-default)`。
  - 聚焦：边框变为 `var(--border-focus)` + 光环。
  - 内置 padding `12px 16px`（左侧）、`12px 56px`（右侧，为发送按钮留空）。
  - placeholder：`"请输入您想咨询的医学问题..."`。
  - 字号 `15px`，行高 `1.5`。
  - 背景 `#ffffff`。
- **发送按钮**：
  - 位于输入框内右侧，绝对定位。
  - 圆形，直径 `36px`，主色填充，白色箭头图标。
  - 无文字状态下置灰不可点击。
  - hover：亮度 +5%。
  - 支持 `Enter` 发送，`Shift+Enter` 换行。

### 7.5 按钮系统

### 7.6 顶部导航栏

## 8. 双角色体验细节

### 8.1 医生侧

- 侧边栏顶部提供快捷分类筛选："全部 / 手术步骤 / 指南文献 / 用药参考"。
- 消息列表 Item 支持右键菜单：重命名、归档、删除。
- 支持键盘快捷键：
  - `Ctrl + K`：聚焦搜索/输入框。
  - `Ctrl + B`：切换右侧信息面板。
  - `Ctrl + N`：新建会话。
  - `Ctrl + D`：切换暗色模式。
- 消息内容区支持代码块内嵌医学公式/检查值，使用等宽字体高亮。

### 8.2 患者侧

- 首次进入对话时展示温和问候卡片（而非空白页）：
  - 标题："您好，有什么可以帮助您的？"
  - 副标题："您可以描述您的症状或健康疑问，我会参考医学知识库为您提供参考信息。"
  - 下方展示 3-5 个推荐问法标签，点击即可填入输入框，例如：
    - "手术前需要注意什么？"
    - "术后恢复期饮食建议"
    - "这个检查结果怎么看？"
- **免责提示条**：固定于消息列表顶部（sticky），柔和暖黄底色（`--color-warning` 浅底），字号 `13px`，内容：
  > ⚠️ 本系统内容仅供参考，不构成医疗诊断或处方建议。如有不适，请及时就医。
- 加载动画：AI 回复等待期间，显示三个跳动圆点 + 心跳波纹（`--color-accent`）。

## 9. 无障碍规范

- 所有可交互元素最小可点击区域 `44×44px`。
- 焦点指示器：`:focus-visible` 时，`box-shadow: 0 0 0 2px var(--bg-canvas), 0 0 0 4px var(--color-primary)`，形成 2px offset 的主色环。
- `Tab` 键导航顺序：顶部栏 → 侧边栏 → 输入框 → 消息区可聚焦元素（引用链接）。
- 所有图标配 `aria-label` 属性。
- 色彩对比度：正文/背景 ≥ 4.5:1（目标 7:1），大号文字（≥18px bold）≥ 3:1。
- `prefers-reduced-motion`：检测用户系统动效偏好，匹配时禁用所有过渡/动画（`transition: none`）。
