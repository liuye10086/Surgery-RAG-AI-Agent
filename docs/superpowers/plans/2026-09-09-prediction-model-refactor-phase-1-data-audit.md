## 2. 贯穿各任务的数据约定

这些是本次审计文件约定，不是拟议的业务数据库 schema。执行时不据此扩展生产接口。

### 2.1 标识、来源与审核

- `source_id`：来源键加该文件 SHA-256 前 12 位；同一目录内多个文件再加顺序号，完整哈希仍存清单。
- `case_id`：`source_id` 加文档中的病例段顺序号；原病例编号另存私有字段 `source_label`，不要求唯一。
- `record_id`：文件内唯一的顺序标识，如 `OBS-000001`；关联使用 `case_id` 和来源引用，不使用姓名作为主键。
- `source_refs`：非空数组，每项含 `source_id`、`part`、`locator`。DOCX 采用部件名与段落序号或表格行列定位，如 `word/document.xml`、`table[2]/row[3]/cell[1]/p[1]`；PDF 采用从 1 开始的页码与表格／区域；表格采用工作表与行列。重合并单元格须记录实际对应范围。
- `review_state`：`candidate`、`verified`、`needs_review`、`excluded`。`verified` 的含义由 `reviews.jsonl` 中审核种类决定，不能由字符串本身推断临床标签获准。
- `reviews.jsonl` 每项含 `review_id`、`target_file`、`target_id`、`review_kind`（`transcription`、`identity`、`clinical`）、`decision`（`verified`、`needs_review`、`excluded`）、`reviewer_ref`、`reviewed_at`、`source_refs`、`reason`。机器自检不能登记成专业临床审核。
- 一个病例段包含多人时，先保留父段，另建有主体证据的子段；不能将共同叙述中的所有指标复制给每位家属。

### 2.2 时间与缺失

每个观测和结局使用相同的 `time` 对象：`kind` 为 `absolute`、`relative`、`interval` 或 `unknown`；同时保留 `raw_text`、`precision`、`date_value`、`anchor_ref`、`offset_value`、`offset_unit`、`lower_bound`、`upper_bound`。不适用的字段为 `null`。

- 仅明确年月日时填写 `date_value`；仅年／月的信息保留原文和精度。相对时间必须注明锚点；无法确认锚点时保持未决，不换算日期。
- 时间区间的边界记录原文和精度，不预设区间内的事件具体日期。只有明确的上下界才用于区间统计。
- `observed` 与 `planned` 分开；计划复查不计作完成访视。后期回顾的历史检查另记 `known_by`，不能假定预测时已经可得。
- 数值、单位、样本类型和方法均允许 `null`，并以 `missing_reason` 区分 `not_recorded`、`unreadable`、`ambiguous`、`not_applicable`。数值 `0` 不代表缺失。

**验收：** 已发生、未记载、观察不足和不适用可以区分；没有人为生成一年结局；所有需要专业判断的结局有审核结果或具体未决项。

## 4. 必查反例与完成条件

以下为审核时的判定示例，不是新增真实病例或项目测试数据，不得混入审计记录。

| 情况 | 必须得到的处理 |
| --- | --- |
| 只有“基线后 14 个月” | 保留相对月份及基线引用，不生成具体年月日或 365 天标签 |
| “建议三个月后复查”，没有实际结果 | `planned`，不增加实际访视次数 |
| 同一正文出现两次 | 保留两个来源段与 `same_text` 关系，身份确认前不宣称两位患者或自动合并 |
| 家系段包含三人，只有一段共有检查叙述 | 未能明确主体的值进入未决队列，不复制三份 |
| 数值 0、缺少单位 | `value_numeric: 0`，单位为 `null`，单位缺失有原因 |
| 末次记载没有进展描述 | 不产生阴性标签，保留证据不足状态 |
| 基线已确诊肝硬化，后续再次提及 | 保留基线既往事件，不能作为未来新发肝硬化阳性 |
| PET 索引的类型字段为 Y | 只表示该字段定义的检查类型，不生成阳性生物标志物 |

本阶段可以交付“盘点已完成，临床核验仍有待办”或“盘点已完成，数据不支持预测”的真实结论；必须明确审核覆盖和缺口。这两种状态均不能写成“正式标签完成”或“模型重构完成”。

进入阶段二计划设计的条件是：已有足以讨论任务的可追溯盘点与限制说明；如果需要补数据，阶段二计划先安排获取及核验。进入阶段三训练的条件仍以总领文档为准：实质任务、临床定义、标签审核、数据版本和评估标准均完成确认。两个病种分别判断。
