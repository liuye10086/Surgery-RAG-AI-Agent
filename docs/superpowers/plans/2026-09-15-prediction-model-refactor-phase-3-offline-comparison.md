## 3. 固定工程实验协议

### 3.1 来源、规模及分区

复用 `GenerationConfig`、`generate_cohort`、`assess_cohort`、`build_engineering_samples` 和 `build_partitions`，不修改它们。

- 种子：`20260914, 20260915, 20260916`。
- 每种子每病种1200名合成主体，开发池800、挑战池400。
- 调用 `build_partitions(samples, seed, train_group_sizes=(640,), validation_fraction=0.2)`：每病种640组训练、160组内部验证、400组挑战。
- 保留现有 `sha256(stability.v1:{seed}:{disease}:{group})` 排序，两个时距不拆患者；以上为当前一组一患者生成器下的预算，实际合格／有标签人数另报。
- 不重新比较120／600档位；相同种子与分区便于同条件核对现有最大档结果。
- 三个种子及生成机制已有历史成绩，本轮属于预先写明新增分析的合成工程比较；不称“未接触的独立临床测试”。
- 先固定协议，再生成新目录与拟合；旧来源、模型及验收输出不覆盖。
- 实际生成前检查当前生成器及依赖源码身份是否仍与历史记录一致；若变更则明示新身份，不声称旧结果可逐项复现。

本轮固定3个种子 × 4任务 × 2模型族 × 5分支 = **120次拟合尝试**。内部验证和挑战只预测、评分；完整复算会重新拟合成功模型，复算调用不额外计为新的实验候选。

### 3.2 历史子集与特征

主资格沿用合成组样契约。历史可用子集 `H` 定义为：

1. 输入 `available`；
2. `history_coverage=complete`、`history_state=observed`；
3. 至少一个严格早于锚点、在锚点时已知、同指标／单位／方法的有效历史观测；
4. 锚点及历史日期唯一，数值有限、时间跨度大于0。

H的资格只读取输入；标签有效性另作拟合／评分筛选。未知历史不填0，确证零历史可进入主分支但不进入H；这与旧D03允许确证零历史的集合不同，不能沿用旧D03样本身份。

T2实现边界：H资格先于派生斜率计算。原始历史满足H、但T1标记 `history_calculation_error` 的行仍保留在四个H分支的共同训练身份中；依赖缺失数值特征的分支记录训练错误，不通过删除该行制造成功。只依赖可用锚点或次数／跨度的分支可继续执行，各分支状态完整保留。

新增特征按固定规则计算：

| 特征 | 定义 | 单位 |
| --- | --- | --- |
| `anchor_value` | 锚点实测值 | 分或U/L |
| `prior_value` | 日期最近的合格历史值 | 分或U/L |
| `slope_per_day` | 所有合格历史加锚点的普通最小二乘时间斜率；x为相对锚点的实际天数 | 分/天或U/L/天 |
| `n_pre` | 严格早于锚点的合格历史日期数 | 次 |
| `span_pre_days` | 最早历史到锚点的实际天数 | 天 |

斜率为 `sum((x-x_mean)*(y-y_mean))/sum((x-x_mean)**2)`。不使用未来值、未来日期、另一个时距标签、来源机制、病例ID或池角色作为特征。无有效跨度时H不可用；计算溢出记错误，不把数值错误改成正常弃权。

### 3.3 五分支与公平比较

| 分支 | 特征顺序 | 训练集合 | 用途 |
| --- | --- | --- | --- |
| `anchor_all` | anchor_value | 全主资格、训练角色、有标签者 | 保留全人群末次值候选 |
| `anchor_history` | anchor_value | H且训练角色、有标签者 | 历史子集的匹配参考 |
| `schedule_history` | anchor_value, n_pre, span_pre_days | 与anchor_history完全相同 | 单独检验随访节奏 |
| `value_history` | anchor_value, prior_value, slope_per_day | 与anchor_history完全相同 | 检验历史数值 |
| `value_schedule_history` | anchor_value, prior_value, slope_per_day, n_pre, span_pre_days | 与anchor_history完全相同 | 检验历史数值之外的节奏增量 |

四个H分支必须有完全相同的训练患者、标签和依赖组；验证／挑战H集合也相同。共享列的训练均值／尺度按浮点容差核对，不能用全人群模型代替H匹配参考。

完整输入都生成各分支的状态记录；非H输入对H分支为 `abstain`，不从原始输出中删除。无未来标签不阻止预测，有标签才进入评分。

### 3.4 训练配置

沿用既有配置：

```python
Ridge(alpha=1.0, fit_intercept=True, solver="svd", positive=False, copy_X=True)
RandomForestRegressor(
    n_estimators=200, criterion="squared_error", max_depth=4,
    min_samples_split=2, min_samples_leaf=3, max_features=1.0,
    bootstrap=True, oob_score=False, random_state=20260914,
    n_jobs=1, warm_start=False,
)
```

两族都仅按该次训练集合计算均值和总体标准差 `ddof=0`；常量列尺度1并记录，不插补、不删除常量列。目标为未来MMSE／ALT原值，不改为差值目标。保留有限越界预测及越界计数；不裁剪、舍入或自动校正。

少于2个独立训练组记 `insufficient_training_support`，仅为工程可运行保护。拟合异常留存首次失败；不换种子、换参数或重试到成功。

### 3.5 评价与结论

每任务、种子、角色、模型族分别报告：

- 全主分支及H的主体／依赖组、资格、标签、预测成功／弃权／错误与配对分母。
- MAE、RMSE、偏差、实际单位及越界计数；各分支与保持末次值的配对增益。
- H上五个预定对照：趋势外推vs保持末次值；schedule_history vs anchor_history；value_history vs anchor_history；value_schedule_history vs value_history；value_schedule_history vs schedule_history。
- 所有差值统一为 `MAE(reference)-MAE(candidate)`，正数表示该比较候选误差更低；明确参考模型，不能把流程增益命名为临床效果。
- 训练／内部验证只给描述统计；挑战对固定模型作依赖组配对bootstrap，95%、2000次、种子20260910，使用现有同抽同重数和失败不补抽规则。
- 相同任务、角色和共同患者集合复用同一抽样计划；集合不同独立保存，不套用旧下标。区间不含重新训练的不确定性。
- 三种子等权汇总均值、最小／最大、有效种子数和增益方向；不合并患者、不同单位或把三点范围当置信区间。
- 对所有分支另外提供同一完整配对集合上的比较；若输出失败使集合改变，展示覆盖差异，不直接按不同子集MAE排名。

T3实现边界：每任务、角色、模型族固定五个候选vs-last及上述五个H对照，分别保留自身配对集合和 `common_complete` 集合的结果。共同集合固定为该任务／角色中H合格、有标签、两族全部10个候选及2个基线均有效的样本；anchor_all在共同集合比较时也限制到该H集合。各模型自身的全人群／H统计仍保留。抽样计划身份绑定任务、角色及实际共同样本身份；仅依赖组相同但患者集合不同，不视为同一个计划。单位及越界沿用既有工程输入契约：MMSE为分、范围0–30，ALT为U/L、非负，不另设ALT上界。

不使用空临床门槛生成“通过”。给出各任务逐项证据表及 `clinical_status=not_assessable`；没有自动选优、自动发布或“全部任务一定可用”的承诺。事后探索须另记，不能冒充本协议预定实验。

- 评价返回 `evaluation/paired_rows/bootstrap_plans`，固定比较位于 `evaluation.comparisons`；每比较明确reference、candidate、role、counts、joint_states、statistics及uncertainty_scope。
- T3的samples由调用者把既有组样行按sample_id与T1的 `history_status/history_reason` 及固定分区的 `pool/evaluation_role` 关联；H按输入状态判定，不能从预测是否成功倒推。评价接口接受全角色样本与预测，先校验全部主体／依赖组不跨角色或池，再按role选择本次评分行；也可接受单角色子集。T4负责来源和分区绑定。
- `aggregate_history_runs` 输入为 `[{"seed": int, "evaluations": [evaluate_history_role返回值, ...]}, ...]`；预定三种子、三角色、四任务、两模型族、十个比较及两个集合范围组成固定汇总目录。缺种子、缺角色或缺比较仍保留对应项并标明不完整；重复或未知身份拒绝。

| 评价 | 只接受`synthetic_prediction_candidates.v1`及固定8条选定比较 | 1440条比较、480条汇总，含角色、共同集合、全部分母与配对区间 | 绑定history协议、候选／参考行、训练及评价来源、覆盖／失败／越界与not_assessable；不把旧校验放宽为任意dict |
| 输出状态 | `numeric_prediction.v2`固定同一算法；预测与末次值基线还要求任务身份及status/reason一致；在线有限越界会抛错 | 候选分别valid／abstain／error，H不足可弃权而末次值仍成功；离线保留有限越界 | 新版本支持逐任务算法及各自状态，明确H不足、计算失败、未提供任务、制品损坏；显式设计越界失败／审计语义，不裁剪、不让基线成功掩盖候选不可用 |
| 快照与报告 | `numeric_generation_context.v2`、`numeric_report_document.v2`、发布指纹v5；接单固定模型参数、参考、检索、提示词及LLM身份 | 离线结果不含报告发布状态 | 必要版本路由与完整性绑定同步更新；旧上下文、旧报告及PDF原件继续按保存事实读取，不调用新模型补算 |
