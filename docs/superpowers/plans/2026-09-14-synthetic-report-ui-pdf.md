# 合成数值报告D包：页面与PDF实施计划

**Goal:** 操作者可识别只读合成病例、显式生成数值报告、读取类型化历史，并准备／下载经过验证的PDF归档原件。

**Architecture:** 服务端只暴露已校验来源的安全能力摘要，前端复用病例、生成观察、历史和归档状态管理。数值文档独立渲染；PDF采用专用模板并纳入renderer身份，沿用既有准备、租约、原子发布、交付和恢复流程。

**Tech Stack:** Python3.11.4、项目venv、Vue3／TypeScript、Node22.15.0／npm10.9.2、现有Playwright／Chromium与受控Noto字体。

## 边界

- 按已确认应用设计第7节D包执行；完整读取并遵循DESIGN_SPEC暖杏蓝、CSS变量、无障碍与动效规范。
- 不调用LLM、不训练或发布模型、不改A／C预测身份和冻结输出；不写业务库、不提交推送部署。
- 新来源摘要只能由服务端验证产生；输入仍只读，普通创建编辑不能提交来源。功能关闭不回退旧报告。
- 保留旧文档、历史和已归档原件；新PDF不即时替代损坏原件。新模板或源码改变需构建独立renderer制品，旧制品保留。
- 重型单元、数据库与浏览器检查串行，日志保存任务目录。仅启停本任务本机隔离进程。
