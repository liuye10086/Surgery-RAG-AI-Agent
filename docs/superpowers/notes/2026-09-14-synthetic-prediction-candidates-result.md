# 合成候选训练、D03比较与规模核查结果

日期：2026-09-14。范围：AD/MMSE与脂肪肝ALT各6／12个月，合成离线工程验证。

**本步已实现并实际运行：24份固定候选模型、2880条预测状态记录、64组比较、32份依赖组抽样计划；结果新进程复算通过。208项不同的相关测试通过。当前每病种120人的队列足以跑通此次受测离线流程，但不足以据此宣称性能稳定或临床有效。**

本轮主分支的8个候选比较，其MAE均高于保持当前值；8个D03流程增益点估计也均为负。保留所有负结果，不择优调整参数、扩大输入或改生成器。下一步建议先固定并执行更大规模／多种子的工程稳定性实验，再进入最小应用与隔离全链路验收。

## 4. 合成病例是否太少

**需要区分用途：当前规模可作为快速工程回归包；它提供的实际拟合／评分支持较少，尤其D03，不能据一次结果认定模型已稳定。** 每病种120人含80开发、40挑战，但主分支实际开发标签仅51—58，D03仅29—38；挑战D03仅15—17。两个时距和多个模型不能相加成更多独立患者。

九次生成、质量和组样检查均通过；六次同种子扩量比较中，五类已有记录逐行内容全部保持。每次生成＋质量＋组样约0.2／0.9／1.9秒，未含训练及区间计算。增加数量可提高同一模拟机制的覆盖，但不会增加机制类别；MMSE整数序列碰撞也随数量上升。1200人／病种时AD开发／挑战的完整值序列唯一数为762／393，跨池有28个相同值序列；该指纹不含日期，不等于28个重复患者或已证实泄漏。

建议保留120包作快速回归，另预先规定600／1200规模、种子、固定候选和开发池依赖组抽样的稳定性方案；同时检查误差、覆盖、失败、重复轨迹和运行成本。学习曲线用于观察样本增加的收益与误差变化，不能只看一个人数门槛判断足够。[scikit-learn学习曲线说明](https://scikit-learn.org/stable/modules/learning_curve.html#learning-curve)

这些扩量档位是工程实验建议，**不是临床最低样本量或已完成的模型稳定性结论**。正式所需真实患者数量仍须结合目标用途、结果分布、依赖结构、性能和精度条件确定；增加同源合成病例不替代真实病例。
