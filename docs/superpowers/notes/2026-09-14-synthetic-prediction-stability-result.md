# 合成规模与种子稳定性实验结果

日期：2026-09-14。范围：AD/MMSE、脂肪肝ALT各6／12个月，固定Ridge与随机森林，合成离线工程分析。

**9单元、216模型已完成，59项相关测试通过。扩量改善部分误差，最大规模下两个角色各8个主分支候选的三种子平均MAE仍未优于保持当前值；新进程独立重算通过。**

## 1. 已固定的实验方法

用户要求执行上一轮提出的规模／种子稳定性实验。本轮在任何正式拟合前保存[实验设计](../specs/2026-09-14-synthetic-prediction-stability-design.md)及[实施计划](../plans/2026-09-14-synthetic-prediction-stability.md)，未根据本轮结果修改模型、机制、规模、分组或指标。

- 种子：20260914／20260915／20260916。每种子每病种生成1200人，原开发800、原挑战400；均沿用旧生成器及组样契约。
- 每疾病按完整依赖组、种子和组ID的固定SHA-256顺序，从开发池保留20%（160组）作固定内部验证，其余取64／320／640组训练。当前一组一患者；两时距和D03分支不拆患者。分组不查看结果、资格、历史次数或机制。
- 图中的120／600／1200是名义规模档位，对应原开发80／400／800的80%训练预算；验证160、挑战400始终保持。**这些曲线不是把此前120人包直接扩成600／1200后的重新划分结果，不能与上轮80人全部训练的数值直接作配对差。**
- 3种子×3档位×4任务×2模型族×3分支，共216次固定拟合。每次仅给训练子集的features/samples，其他角色只作预测。标准化、D03同训练集合、缺标签／历史未知／确证零历史、失败不重试沿用旧契约。
- 分别保存训练、内部验证及挑战的全候选预测、全基线预测、配对行、输出状态和分母。保持当前值与D03仅锚点参考分开，负结果照常保留。

跨种子按三个点估计等权报告均值、最小／最大及有效种子数，**不合并患者，也不把范围称为置信区间**。本轮没有置信区间宽度、稳定性或临床准入阈值，不会据图形平稳就标记“已充分”或“临床通过”。此前固定模型的2000次区间仍原样保存在旧包中，其条件区间不能代替本轮重新训练的波动。

## 2. 实际结果

**扩量有部分收益，但本轮扩至1200人／病种仍未使固定候选的平均MAE优于基线。** 从120到1200名义档位，按三种子平均MAE，开发验证集5／8个任务×模型组合改善，挑战集6／8改善；最大档两个角色各8个候选的平均MAE仍全部高于对应保持当前值基线。这里比较的是三个种子的等权均值，不表示每个种子或每名患者都相同。

实际216／216模型拟合成功，候选预测194,688条、基线预测64,896条，864组比较、288条跨种子汇总。全部状态、分母和失败保留；重复训练、两个时距和多个模型的输出数不等于独立患者数。

| 120 | 64 | 41–52 | 21–35 |
| 600 | 320 | 211–236 | 141–158 |

以上范围跨任务和种子。固定内部验证每任务有效标签102–119人，D03为60–84人；固定挑战每任务有效标签268–292人，D03为159–193人。各档内部验证与挑战评分患者集合相同、D03配对训练名单相同、各分支真实训练名单嵌套，均已在完整结果分析中逐项核对。

D03流程增益为“仅锚点MAE−加入次数／跨度MAE”。最大档开发验证4／8个组合均值为正，挑战仅1／8；两个角色都没有任何组合在三个种子中全部为正。挑战唯一正均值为ALT12个月随机森林：+0.0086 U/L，逐种子为+0.0768／+0.5678／−0.6188，方向并不一致。训练—验证差的24个规模×任务×模型均值中8个为负，不能把所有变化统称过拟合。

## 5. 解释限制与后续步骤

从生成器代码可核对，访视次数／日期由`visits_rng`生成，轨迹参数由`trajectory_rng`生成；开发机制为linear／curved，挑战为piecewise／periodic且噪声更高。扩量保持这些结构，不能自动新增次数／跨度与未来结局之间的预测关系。这是对实现的结构性解释，不是本轮已完成的因果归因实验。D03只比较次数／跨度，不代表利用全部历史数值的纵向模型。

本轮只能评价固定生成机制、固定双候选及三种子下的工程表现；没有计算正式临床样本量，没有证明真实泛化，也没有根据挑战池结果调参或选出发布模型。

1. **下一步：制定最小应用接入方案，明确合成任务、模型、报告和来源标识的接入边界与隔离验收条件。** 随后实施并验收权限、预测、持久任务、历史和PDF归档。
2. 真实资料到位后独立完成A2事实／定义、A3组样及泄漏核查、A4样本支持／评价契约／门槛、A5审核冻结。
3. 阶段三在冻结真实数据上完成基线、候选和纵向增量的独立比较。
4. 阶段四正式报告契约及兼容接入；阶段五按授权发布、核对回退并持续评价。

原36项临床验收仍为13满足、15缺条件、8未执行，合成扩量不替代真实A3准入。
