## 2. 方案比较与推荐

| 方案 | 收益 | 取舍 |
| --- | --- | --- |
| **推荐：固定 Ridge＋小型随机森林** | 覆盖正则化线性回归和树模型两种路径，能检查统一输入、状态、拟合隔离及成对评价 | 要维护两类工程制品；固定参数不代表寻优或临床最优 |
| 仅固定 Ridge | 实现最小，系数与标准化容易独立核对 | 树模型路径仍需后续补验收 |
| 多候选＋开发池分组调参 | 可演练参数选择和内部评价 | 需要另定折数、嵌套和失败合同；当前工程包无需增加这部分范围 |

推荐第一项；不根据已经看到的挑战池基线成绩调整参数或输入，不在本包引入基础模型、模型权重下载或新依赖。总领中未来可比较的方法仍保留，但不自动进入本包。

官方资料说明 [Ridge](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html) 使用 L2 正则化平方误差，`svd` 可处理奇异设计矩阵；[RandomForestRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestRegressor.html) 提供树深、叶节点样本数和随机状态参数。这些支持配置的技术含义，不构成本项目性能证据。网页当前为1.9.1文档，本地已核对安装版本和构造签名为 scikit-learn 1.9.0，实施继续使用项目版本。

## 4. 拟合方案与输入

每个任务、每个候选族拟合以下三份模型，共24份拟合尝试记录。拟合前固定样本ID列表、特征顺序及哈希，按 `sample_id` 排序：

| 分支 | 输入顺序 | 训练集合 | 评价范围 |
| --- | --- | --- | --- |
| `main_anchor` | `anchor_value` | 开发池主资格满足且标签有效者 | 全部主分支锚点输出，标签有效者评分 |
| `d03_anchor` | `anchor_value` | 开发池主资格满足、历史范围已知且标签有效者 | D03 已知历史子集 |
| `d03_augmented` | `anchor_value, n_pre, span_pre_days` | 与同任务同族 `d03_anchor` 完全相同 | 与 `d03_anchor` 同患者、锚点、目标和池 |

**D03 对照两侧都在同一开发子集重新拟合。** 不直接拿使用更多训练患者的 `main_anchor` 当 D03 参考模型。共享列的训练均值／尺度应相等，两个 D03 制品记录同一训练集合哈希。

预测函数只接受显式特征投影与已拟合模型；`sample_id` 等身份字段仅关联，不进入矩阵。拟合层仅接收开发池经过资格检查的 X/y，不能收到挑战标签。未来目标日期、工程池、生成机制、依赖组ID、年龄、治疗、另一个时距目标以及历史值／斜率均不进入本包候选矩阵。现有 D02 历史外推结果保留，本包 D03 只检验复查次数／跨度的流程增量，不据此宣称已验证所有纵向信息。

确定性工程配置拟固定如下，未列出的构造参数沿用已核对的1.9.0默认值，并将完整 `get_params(deep=False)` 保存：

- `Ridge(alpha=1.0, fit_intercept=True, solver="svd", positive=False, copy_X=True)`。
- `RandomForestRegressor(n_estimators=200, criterion="squared_error", max_depth=4, min_samples_split=2, min_samples_leaf=3, max_features=1.0, bootstrap=True, oob_score=False, random_state=20260914, n_jobs=1, warm_start=False)`。
- 模型训练每患者等权；随机森林内部有放回抽样属于已固定算法，评价区间仍按依赖组抽样，两者不混称。全部任务／分支使用相同固定种子，禁止失败后换种子。
- 两族均按该次训练集合逐列计算 `mean`、总体标准差 `ddof=0`；只有标准差为0时尺度记1并记录常量列。训练外应用保存参数，常量训练列遇到新值仍按公式转换。用既有 NumPy 明确实现该算式，不依赖库对近常量列的额外处理。
- 目标直接为未来 MMSE／ALT 原单位实测值，不预测经变换目标；无插补、特征筛选、裁剪、舍入、输出校正或个人预测区间。有限负数、超量表值仍保存并在失败分析描述；非有限输入／参数／输出记错误。
- 无合格训练行，或少于2个独立训练依赖组，记 `insufficient_training_support`，不拟合。此为工程最低可运行保护，不是正式样本量准则；常量输入／目标不因其常量被静默删除，拟合及校准描述分别按实际可估计性记录。

## 5. 评分、D03 增量及失败

复用 `prediction_calculation_metrics.py` 的患者等权 MAE、RMSE、偏差、保持当前值配对改善及 alpha／beta 描述。新增比较编排，不改变原两基线枚举或上包源码身份；`evaluate_baselines` 写死了现有两个模型及基线语义，不能直接冒充支持候选。

候选正式口径的工程描述始终是 `mae_gain_vs_last = MAE(last_value)-MAE(candidate)`。D03 另设 `flow_mae_gain = MAE(d03_anchor)-MAE(d03_augmented)`，只在同任务、同族、同池的共同可评分子集计算。两项明确记录参考模型，不能把 D03 增益送进针对保持当前值的 `performance_decision`。如调用底层通用成对统计帮助计算，必须在专用 D03 适配中重命名并隔离参考语义。

D03 三方（仅锚点、增加流程、保持当前值）的数值及子集分别保存。两模型之一失败时，仍保留失败与其同伴输出；共同可评分统计只描述交集，不能覆盖全分母。不同候选族也分别报告覆盖，不直接拿不同子集的 MAE 判断胜负。本包不生成胜出／推荐发布标记。

开发池仅报告训练内描述。挑战池对固定拟合模型执行95%、2,000次、PCG64种子20260910、按排序依赖组同抽同重数的配对区间，沿用线性分位数及失败不补抽规则；D03 的两侧与其增益使用同一组抽样计划。参考模型和评分集合发生变化时保存独立计划；不跨不同集合套用旧索引。区间不包含模型重新训练的不确定性，也不构成显著性筛选或真实覆盖保证。

逐模型保留 `valid/abstain/error`：输入不适用或D03历史未知为 `abstain`；缺模型、拟合失败、非有限或计算异常为 `error`。确证零历史的0／0可进入D03，未知不能填0。标签缺失不阻止输入合格者预测，缺标签者不评分。为所有原输入及预声明分支保存输出状态，缺记录计error；分母、标签状态、联合四态及零分母null沿用既有规则。

没有模型／数据失败重试；CLI默认不自动重试。已确认的最多一次基础设施重试只是上限，本包若另作明确的临时IO重试，须固定输入／参数／随机状态并保存两次尝试，不能作用于数据或统计失败。性能仍为 `not_assessable`，保留已知失败；工程完整性通过与某候选全部成功分开表达。
